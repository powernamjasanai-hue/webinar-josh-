## 3가지 트랙 구조

### ✍🏻 크리에이터 트랙 — 오디언스를 모으는 법

- 매주 수요일 그룹 컨설팅 (조쉬 직강)
- 스레드/링크드인/뉴스레터 글쓰기 (롱폼/숏폼/AI)
- SNS에서 팔로워를 얻는 방법 + 챌린지를 통한 오디언스 획득

### 🔨 빌더 트랙 — 나만의 상품을 만드는 법

- 바이브코딩으로 실제 워킹하는 풀스택 제품 제작
- 노코드/로우코드 도구로 빠르게 MVP 론칭
- 세일즈에 필요한 반복 업무 자동화 (이메일 자동 발송, 고객 관리 시스템 등)

### 🛒 세일즈 트랙 — 만든 상품을 파는 법

- 온라인 퍼널 구축 + 상품 판매 방법
- 판매 전환을 높이는 랜딩페이지 기획법과 제작 방법
- Tally + Make + Notion 자동화 시스템
- 실전에 바로 투입하여 실제 수익화 도모

## 핵심 선순환 구조

```
크리에이터(알리고) → 빌더(만들고) → 세일즈(팔고) → 다시 콘텐츠 제작에 집중
```

트래픽을 모았다면, 이제 뭘 팔 것인가?
상품을 만들었다면, 이제 어떻게 팔 것인가?
판매가 자동화되면, 다시 콘텐츠 제작에 집중

**3가지가 선순환하면서, 진짜 매출 내는 사업자가 될 수 있습니다.**
