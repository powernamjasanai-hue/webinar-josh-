## 웨비나 커리큘럼

### Part 1. 6가지 수익화 모델 설명
실제 매출 데이터 + 사례 6개의 퍼널
- 외주
- 컨퍼런스
- 멤버십 커뮤니티
- 코호트 챌린지 코스 (4주)
- 디지털 상품 판매
- 그 외 기타 (기업강의, 광고)

각 상품별 세일즈 구조를 단계별로 공개, 구축 방법

### Part 2. 세일즈 엔진 설계법 (3단계 '육성 + 긴급형' 세일즈 퍼널)

**Awareness → Desire → Action**을 모두 자동화로 연결하는 세일즈 엔진 설계법

#### Attention
- 소셜미디어로 유입을 만드는 시스템
- 통하는 콘텐츠 종류와 사례
- 고객을 모으는 리드마그넷 기초

#### Desire
- 미끼 상품 or 본 상품을 '지금 살 수 없게' 하여 구매욕 육성하는 구조
- '대기'를 활용하는 구매 심리 장벽 낮추기
- 대기리스트 이메일/SMS 마케팅

#### Action
- '지금' 구매하도록 유도하는 구조
- 프로모션 제공 방법
- 결제 플로우 설계법

### Part 3. Tally + Make + Notion 자동화 시스템 구축 시연
- 문의부터 결제까지 자동으로 돌아가는 실제 시스템을 라이브로 시연
- SNS 내 알림 포스팅 홍보 포스팅 제작 시연
- 자동화 마케팅 연동 시연
