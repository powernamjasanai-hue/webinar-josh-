# ASC 4기 웨비나 랜딩페이지 기획안 & 카피

## 마케팅 전략 개요

### TAM(시장 크기) 확장 전략

**기존 뉴스레터 오디언스 (레드오션)**
- 이미 조쉬를 알고
- 이미 솔로프리너에 관심 있고
- 이미 팔로우 중
- → 한정된 시장

**vs**

**"퇴사 고민하는 대기업 직장인" 시장 (블루오션)**
- 한국에 수십만 명
- 매년 퇴사 고민
- 검색량 높음
- 페이드 광고 타겟팅 쉬움
- → 거대한 시장

---

### 페이드 마케팅 메시지 전략

| 구분 | "전문성 수익화" (고급) | "퇴사 불안" (대중) |
|------|----------------------|-------------------|
| 타겟 범위 | 좁음 | 넓음 (대기업 직장인 전체) |
| CPA | 높을 가능성 | 낮을 가능성 |
| 감정 자극 | 낮음 | 높음 → CTR 높음 |
| 검색 키워드 | 적음 | 많음 ("퇴사 준비", "사이드 프로젝트", "N잡") |

**선택: "퇴사 불안" 메시지로 대중 타겟팅**

---

### 깔때기 전략 (Funnel Philosophy)

**"넓은 입구 → 좁은 출구" 모델**

```
[넓은 입구]
광고소재: 대기업, 정년 (타겟 언어), 사이드 프로젝트 키워드 사용
랜딩페이지: "퇴사 고민하는 지불여력이 높은 IT 베이스 직장인"
↓
[웨비나 참석]
실제 내용: 고급 세일즈 시스템, 자동화, 퍼널
↓
[ASC 가입]
실제 고객: 의사, 대기업 매니저, 개발자
(이미 전문성 있고, 학습 능력 높고, 지불 능력 있는)
↓
[좁은 출구]
최종 생존자: 진짜로 실행하는 상위 20%
```

**이 전략의 이유**
1. 랜딩페이지는 낮은 장벽으로 최대한 많은 사람 유입
2. 웨비나에서 레벨 필터링 (고급 내용 보고 "어렵네" → 이탈)
3. ASC는 자동으로 퀄리티 필터링됨 (진짜 하려는 사람만 결제)

```

① '연 5억을 넘게 버는 솔로프리너' 1인 창업가 리포트 100개+
② 세일즈 퍼널 체크리스트 - 상품 유형별 실전 가이드

받는 방법:
신청 후 카카오톡 단톡방 링크 클릭 → 공지사항 다운로드 링크 클릭 → 다운로드
```
